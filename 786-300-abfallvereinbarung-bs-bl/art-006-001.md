# Ziffer 6.1
1 Diese Vereinbarung wird auf die Dauer von 15 Jahren ab Inkrafttreten abgeschlossen. Ohne Kündigung gilt die Vereinbarung als stillschweigend auf unbestimmte Zeit verlängert. Sie kann nach Ablauf von zwölf Jahren jeweils mit einer Kündigungsfrist von drei Jahren auf ein Jahresende gekündigt werden.
