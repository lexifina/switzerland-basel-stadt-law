# § 7 Kontrollschild-Deponierung
1 Wird ein Fahrzeug mit ersteigerten Kontrollschildern ausser Verkehr gesetzt und werden die Schilder deponiert, so bleiben sie für die Halterin oder den Halter ein Jahr reserviert. Die Deponierungsfrist kann auf schriftliches Gesuch hin ein Mal um höchstens eine Periode verlängert werden. Wird innerhalb dieser Frist kein Fahrzeug auf die ersteigerte Kontrollschildnummer in Verkehr gesetzt, so erlischt die Nutzungsberechtigung und das Kontrollschild wird erneut einer späteren Versteigerung zugeführt. Der Ersteigerungsbetrag wird nicht rückerstattet.
