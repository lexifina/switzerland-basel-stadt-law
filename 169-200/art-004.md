# § 4
1 Personalgeschäfte von zentraler Bedeutung werden direkt dem Sozialpartnerschaftlichen Gesprächsgremium (SPG) zur Behandlung zugewiesen.
2 Personalgeschäfte von alltäglicher Bedeutung werden im Kontaktgespräch behandelt.
3 Kann bei Personalgeschäften von alltäglicher Bedeutung Einigung erzielt werden, so erstellt HR BS via Finanzdepartement dem Regierungsrat – sofern ein regierungsrätlicher Entscheid notwendig ist – einen entsprechenden Bericht. Kann keine Einigung erzielt werden, so werden diese Geschäfte ebenfalls dem SPG zur Behandlung zugewiesen.
4 Über das Kontaktgespräch wird eine Aktennotiz erstellt.
