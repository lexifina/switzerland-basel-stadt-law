# § 19 Verzicht auf Nutzungsrechte an Familiengräbern
1 Verzichten Nutzungsberechtigte auf ein Nutzungsrecht an einem Familiengrab, so fällt das Grab ohne Entschädigungsanspruch an das den Friedhof betreibende Gemeinwesen zurück.
2 Ein Verzicht während laufender Ruhezeiten ist nur möglich, wenn sämtliche anfallenden Kosten bereits im Voraus gedeckt sind.
3 Die Stadtgärtnerei verfügt unter Berücksichtigung allfällig laufender Ruhezeiten frei über das Familiengrab und kann insbesondere das Nutzungsrecht neu vergeben.
